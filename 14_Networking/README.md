# Networking in C#

This folder introduces basic networking concepts in .NET.

## Topics covered

1. TCP client
2. TCP server
3. HTTP client
4. UDP client
5. UDP server

## Notes

- TCP is connection-oriented and reliable.
- UDP is faster and connectionless.
- HTTP is used for web APIs and browser communication.

## Recommended order

1. Study TCP server/client
2. Learn HTTP client
3. Learn UDP basics
4. Move into ASP.NET Core Web APIs
