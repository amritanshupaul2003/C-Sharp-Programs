# C# Learning Roadmap

This repository is a beginner-friendly C# learning codebase inspired by Java learning repositories like the Java Programs collection.

It is organized topic by topic so you can learn C# from basic programming to .NET fundamentals.

## Learning order

1. Basics
2. Operators
3. Conditional Statements
4. Loops
5. Patterns
6. Functions and Methods
7. Arrays and Data Structures
8. Strings
9. OOPs
10. Pointers and Unsafe Code
11. Recursion
12. Collections and LINQ
13. Exception Handling
14. File I/O
15. .NET Development Essentials

## Important note

This is a learning repo, so each file focuses on one concept at a time. That keeps the code simple and easy to understand.

## Suggested next steps after this repo

- Learn C# syntax and OOP deeply
- Practice LINQ and collections
- Learn ASP.NET Core MVC/Web API
- Work with Entity Framework Core
- Build small projects and REST APIs
