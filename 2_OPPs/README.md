# OOPs in C#

This folder was built by studying the Java OOPs folder at `13_OPPs` and translating the same learning flow into C#.

## Learning order

1. Class and Object
2. Methods
3. Encapsulation
4. Access Modifiers
5. Getter and Setter
6. Constructor
7. Method Overloading
8. Inheritance
9. Polymorphism
10. Abstraction
11. Interface

## Concept focus

Each file explains one OOP concept clearly and in isolation so the logic stays easy to understand.

## Java mapping

The examples are based on the same types of Java programs such as:
- class creation and object creation
- method calling
- encapsulation with private fields
- access modifiers
- getter/setter patterns
- constructor usage
- method overloading
- inheritance and polymorphism
- abstraction and interface
